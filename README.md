# Beam Shear Lab — deployment package

## Deploy to a public link (Streamlit Community Cloud)
1. Create/sign in to GitHub and make a new repository.
2. Upload `app.py` and `requirements.txt` from this folder to the repository root.
3. Open https://share.streamlit.io/ and connect GitHub.
4. Choose the repository, branch, and `app.py`, then click **Deploy**.
5. Streamlit will provide a public app URL.

This is a Streamlit web adaptation of the supplied Matplotlib desktop program. The original GUI-specific controls (Matplotlib RadioButtons/Sliders and 3D scene) were adapted to browser-native sidebar sliders and plots. The cross-section display is schematic.
